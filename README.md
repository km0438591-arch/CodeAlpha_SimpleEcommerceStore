# 🛒 Simple E-commerce Store - CodeAlpha Task 1

A simple Node.js based E-commerce Store with cart functionality.

## Features
- Product listing
- Add to Cart / Remove from Cart
- Cart total calculation
- Responsive UI

## How to Run
1. Clone repo: `git clone https://github.com/km0438591-arch/CodeAlpha_SimpleEcommerceStore.git`
2. Install: `npm install`
3. Run: `node server.js`
4. Open: http://localhost:3000

## Tech Stack
Node.js, Express.js, HTML, CSS, JavaScript
